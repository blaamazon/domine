# Domine — Code Workflow

## Repository

- **GitHub**: `blaamazon/domine`
- **Branch strategy**: `main` (production) → feature branches off `main`
- **PRs required**: All code changes go through pull requests

## Process

1. **Clone** the repo to your home directory
2. **Create a feature branch** from `main`: `git checkout -b feat/your-feature`
3. **Make changes** and commit with conventional commits
4. **Push** your branch and create a PR to `main`
5. **Tag** the lead for review in the PR

## Architecture Docs

The system architecture is in `/home/team/shared/architecture/`. All team members should refer to these docs before coding.
